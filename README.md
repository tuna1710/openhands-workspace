# OpenHands Workspace

Môi trường tự động chạy **OpenHands AI Agent** trên **GitHub Codespaces**.

## 🚀 Hướng dẫn khởi chạy nhanh

1. Mở Codespace trên repo này:
   [![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/tuna1710/openhands-workspace)

2. Trong Terminal, chạy lệnh:
   ```bash
   ./start.sh
   ```

3. Chờ 15-20 giây, mở tab **Ports** ➔ Port **3000** ➔ Bấm **Open in Browser** để vào giao diện OpenHands.

4. Cấu hình Model AI (Settings ➔ LLM):
   - **Provider**: `Gemini`
   - **Model**: `gemini/gemini-3.8-flash`
   - **API Key**: Dán Gemini API Key từ [Google AI Studio](https://aistudio.google.com/)
